## 怎么用测试IP自己测：手把手教程

光知道测试IP不够，得会测。下面是几个常用方法。

**第一步：基础延迟测试**

Windows打开cmd，Mac/Linux打开终端，直接ping测试IP。比如测东京：

bash
ping 154.12.190.32


看三个值：平均延迟、抖动（最大最小之差）、丢包率。延迟稳定在50-80ms且丢包0%就是好结果。

**第二步：路由追踪**

看数据包走了哪条路。Windows用tracert，Linux/Mac用traceroute或mtr：

bash
mtr -r 154.12.190.32


重点看回程路由。CN2 GIA线路的特征是回程能看到59.43开头的电信CN2节点。如果回程走的是普通163线路，那就不算真CN2 GIA。

**第三步：测速文件下载**

每个Looking Glass页面都提供100M和1G的测速文件。用wget或curl下载测实际带宽：

bash
curl -o /dev/null http://sg1.lg.bytevirt.net/100MB.test


**第四步：多时段对比**

晚高峰（国内时间20:00-23:00）一定要测一次。很多线路白天漂亮晚上炸，ByteVirt的CN2 GIA在晚高峰表现相对稳定，但住宅IP机房（香港）可能会有波动。
